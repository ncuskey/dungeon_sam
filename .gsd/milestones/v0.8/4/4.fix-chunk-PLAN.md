# Fix: Vite Chunk Size Warning

## Problem
A chunk size warning (> 500kB) appears during the build process, indicating that the production bundle is too large and could impact load times.

## Root Cause
All large dependencies (`three`, `@react-three/fiber`, etc.) are bundled into a single vendor chunk.

## Tasks

<task type="auto">
  <name>Configure Code Splitting</name>
  <files>vite.config.ts</files>
  <action>
    - Update `vite.config.ts` to include a `build` section.
    - Inside `build.rollupOptions.output`, configure `manualChunks` to split large packages.
    - Assign `three` and `@react-three` to their own named chunks (e.g., `vendor-three`).
    - Optionally raise the `chunkSizeWarningLimit` to `1000` to prevent warnings for the `three.js` chunk itself.
  </action>
  <verify>npm run build</verify>
  <done>The project builds without exceeding the chunk size limit warnings for the main application bundle.</done>
</task>
