# Plan 4.1: Level Progression

## Objective
Enable continuous gameplay by transitioning the player to a freshly generated level when they step on the exit tile, retaining their inventory.

## Context
- .gsd/SPEC.md
- src/store/gameStore.ts
- src/components/HUD.tsx

## Tasks

<task type="auto">
  <name>Implement Next Level Action</name>
  <files>src/store/gameStore.ts, src/components/HUD.tsx</files>
  <action>
    - Add `level: number` (initialized to 1) to the `GameState` and `useGameStore`.
    - Create a `nextLevel: () => void` action that calls `generateDungeon()` and overwrites `map, playerPosition, exitPosition, enemies, items, lights, exploredMap`, and increments `level`. Do NOT reset inventory!
    - Update `moveForward` and `moveBackward`: check if the target `[newX, newY]` matches `state.exitPosition`. If so, trigger `get().nextLevel()` and return `{}` to halt immediate physics motion.
    - Inside `HUD.tsx`, pull `level` from the store and display `LEVEL: {level}` centrally or top-left.
  </action>
  <verify>npm run dev (Walk to the red exit tile on the minimap and ensure the map regenerates and the level counter increments)</verify>
  <done>Player enters the exit tile, immediately spans a new layout, and retains their items and health.</done>
</task>

## Success Criteria
- [ ] Game state exposes a `level` counter which is visible on the HUD.
- [ ] Stepping onto the exit tile automatically generates a new procedural level layout while preserving player inventory.
