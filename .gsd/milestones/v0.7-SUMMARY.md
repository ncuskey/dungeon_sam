## Lessons Learned
- **Asset Integrity:** AI-generated assets must be explicitly checked for native alpha transparency. False backgrounds (e.g. checkerboards) can cascade into unhandled `useTexture` suspense errors that crash the entire WebGL rendering pipeline.
- **State Logic Consolidation:** Embedding collision rejection blocks explicitly inside `gameStore.ts` movement reducers cleanly enforces positional bounds without bloating the standard React components.
