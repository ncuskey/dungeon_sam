# Plan 3.1: Level Scaling and Balance Integration

## Objective
Update the dungeon generation to accept a `level` parameter so that enemy spawn rates and static item drops scale progressively as the player explores deeper.

## Context
- .gsd/SPEC.md
- src/utils/dungeonGenerator.ts
- src/store/gameStore.ts

## Tasks

<task type="auto">
  <name>Pass Level to Generator</name>
  <files>src/utils/dungeonGenerator.ts, src/store/gameStore.ts</files>
  <action>
    - Update `generateDungeon` signature in `dungeonGenerator.ts` to accept a `level: number = 1` argument.
    - In `gameStore.ts`, pass `state.level + 1` when calling `generateDungeon` inside the `nextLevel` action.
    - For initial map generation and `resetGame`, ensure it passes `1` (or relies on the default).
  </action>
  <verify>grep "generateDungeon(state.level + 1)" src/store/gameStore.ts</verify>
  <done>The upcoming level number is successfully passed into the generator on each floor change.</done>
</task>

<task type="auto">
  <name>Scale Spawns by Level</name>
  <files>src/utils/dungeonGenerator.ts</files>
  <action>
    - Modify the initial static item spawns to be progressive based on the `level`. For example:
      - Level 1: Goblin Club, Iron Shield
      - Level 2: Sword of Truth, Iron Shield
      - Level 3: Bow and Arrow, Poison Shield
      - Level 4+: Watcher Sword, Poison Shield
    - Update the enemy spawn roll logic to scale with `level`. For instance, make the chance for a `watcher` or `rubble` to spawn increase relative to `level` (e.g. shift the probability thresholds so harder enemies appear more often deeper down).
  </action>
  <verify>grep "level" src/utils/dungeonGenerator.ts</verify>
  <done>Item drops and enemy spawn rates scale progressively with the dungeon depth.</done>
</task>

## Success Criteria
- [ ] Deeper levels contain tougher enemies on average.
- [ ] Deeper levels contain better static item spawns.
