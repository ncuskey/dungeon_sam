# Plan 3.2: Loot Drops & Poison Shield Logic

## Objective
Trigger enemy-specific weapon and shield drops up on death.

## Context
- .gsd/SPEC.md
- src/store/gameStore.ts
- src/components/ItemRenderer.tsx

## Tasks

<task type="auto">
  <name>Process drops on enemy death</name>
  <files>src/store/gameStore.ts</files>
  <action>
    - Inside `playerAttack`, when calculating `newHp`, if the enemy reaches `<= 0` HP, create an item on their `[enemy.x, enemy.y]` coordinate.
    - If `enemy.type === 'watcher'`, drop either `Watcher Sword` or `Poison Shield`.
    - Otherwise, drop either `Sword of Truth` or `Iron Shield`.
    - Push this generated item into the returned `items` array replacing `state.items`.
  </action>
  <verify>npm run dev (kill an enemy to witness a drop)</verify>
  <done>Defeated enemies consistently spawn an item on their previously occupied tile.</done>
</task>

<task type="auto">
  <name>Render specific loot textures</name>
  <files>src/components/ItemRenderer.tsx</files>
  <action>
    - Update `getItemTexture` to read `itemName`. If it includes `"Poison"`, return `'/poison_shield.png'`. Else if it includes `"Shield"`, return `'/shield.png'`. 
    - If it includes `"Sword"`, return `'/sword_truth.png'`.
  </action>
  <verify>npm run dev</verify>
  <done>Poison shields are visually distinct from Iron shields when spawned ingame.</done>
</task>

## Success Criteria
- [ ] Enemies drop items according to their programmed loot tables when defeated.
- [ ] Unique assets load depending on item name conventions.
